Connect Firebase (Free)

For real multiplayer across different devices, you need a free Firebase Realtime Database. It takes about 3 minutes to set up and the free tier supports all your friends.

1
Go to console.firebase.google.com → Create project → name it anything (e.g. cricauction)
2
In your project → Build → Realtime Database → Create database → Start in test mode
3
Go to Project Settings (⚙️) → Your apps → Add app → Web (</>) → Register app → Copy the firebaseConfig values below
4
Paste the values into the fields below and click Save & Connect
